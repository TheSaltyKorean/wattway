# /api/ holds the plan-counter beacon (worker/plan-counter), which counts every
# request it receives. There is nothing there to index, and a crawler hitting it
# would inflate the plan count in the daily usage report.
#
# The Disallow is repeated in EVERY group on purpose. A crawler obeys only the
# most specific group that matches its user-agent and ignores `User-agent: *`
# entirely, so a named agent whose group omitted this line would still crawl
# /api/ no matter what the wildcard group said.
#
# NOTE: this file is not necessarily what a crawler receives. Cloudflare's
# "managed robots.txt" feature, when enabled on the zone, PREPENDS its own block
# that sends `Disallow: /` to GPTBot, ClaudeBot, CCBot, Google-Extended,
# Applebot-Extended, Amazonbot, Bytespider and meta-externalagent, along with a
# `Content-Signal: ai-train=no`. That is the exact opposite of the intent below.
# If AI crawlers are being turned away, check the Cloudflare dashboard
# (AI Crawl Control / robots.txt) before editing this file — the origin cannot
# override an edge-injected block from here.

Disallow: /api/
